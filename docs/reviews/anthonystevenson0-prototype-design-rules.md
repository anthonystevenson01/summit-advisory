**The Coder's note that the advisory path does not require `retried === true`.** Acceptable. The only way to reach the block without a retry is `remaining() < RETRY_MIN_MS`, that is, the press has no time left to retry. In that case the alternatives for a design only screen are kept previous (on an Update) or `invalid` (on a Create), which are the two outcomes the spec names as forbidden for a design line ("never kept-previous and never `invalid`", "never a hard failure"). Accepting the screen with the lines recorded is the reading that honours the spec on both paths; and when there is time, the checks still go through the one retry first, as the spec requires, because the retry block runs before the advisory block. Requiring `retried` would re-introduce a hard failure on exactly the path where the spec forbids one. The record's `retried: false` plus a `notes` field makes the no retry case visible when it happens.

## Security

- Nothing a prospect types reaches the stylesheet unescaped: every colour still passes `colour()` (`/^#[0-9a-f]{6}$/i` or the fallback) and every font stack passes `fontValue()`; `--accent` and `--on-accent` derive only from already validated hex through `darken` (which emits `#` plus six hex digits) or are the literal `#FFFFFF` or the validated text colour; `--text-muted` is a constant.
- Regex safety, reasoned per pattern and timed on hostile inputs of 16,000 to 40,000 characters (all under 250 ms, with the existing checks running in the same call): `CHART_OPEN_RE` and `ROW_STYLE_RE` are sequential bounded classes, no nested quantifiers, worst case quadratic in one tag's length; `SVG_RE` is a lazy scan to the next `</svg`, linear per start; `CSS_RULE_RE` and the selector and background regexes are linear; the dynamic `tagRe` in `chartInner` is built from a capture limited to `[a-z][a-z0-9-]*`, so no regex metacharacter can be injected. Global regexes are used only with `matchAll` and `match`; `test` is only called on non global patterns, so there is no `lastIndex` state between screens. Nothing throws: `open.index` is always defined from `matchAll`, `match` results are null guarded, and `darken` cannot receive a non hex string.
